# 且听风吟 · intellegenceOpcBI

个人工具集之 AI 小智囊看板。

本地技术情报 Web 看板。Python 3.9+，无需第三方依赖。

## 运行

```sh
python3 server.py
```

打开 http://127.0.0.1:8765 。首次启动自动抓取，服务运行期间每 24 小时更新。页面每分钟读取缓存，也可手动刷新。停机期间不更新，重启补更。

```sh
python3 server.py --refresh # 单次抓取，可交给系统定时任务
python3 server.py --port 9000
```

## 三个标签页

- 数据库：PostgreSQL、MongoDB、AWS Database、Azure SQL 的技术及业务动态。
- AI：TechCrunch AI、Google Research、Hugging Face，自动生成候选应用、前提、验证方案、指标与风险。
- FDE：前线部署工程师，聚合 Simon Willison、The New Stack 的 Agent、集成、生产部署等关联信号，配合编辑展望框架。

分析为标题和 RSS 摘要驱动的规则初评，未接大模型，未核验正文。FDE 展望是编辑框架，不是自动新闻研究。新闻保留原语言，全球覆盖不保证完整。默认近 7 天，可搜索及调整日期范围。未提供日期的文章仅在全部时间展示。

来源失败会保留上次缓存并标记，信息源面板显示错误。可修改 server.py 中的 SOURCES。缓存 data/news.json 不入 Git，不预填模拟新闻。服务仅监听本机。

本目录使用 Git 管理，远程仓库为 https://github.com/maning711/intellegenceOpcBI 。用 git status / git log 查看版本。

## 中英文对照、周报与 OPC

- 使用提供的「且听风吟」Logo。英文新闻保留标题与原文摘要，中文标题和摘要在卡片进入视口时自动翻译，逐条排队；翻译结果缓存在 data/translations.json，可点击重试。
- 翻译使用 MyMemory 公共服务，将公开新闻标题和摘要发给该服务；不需要密钥。免费额度或网络失败时显示原因并保留原文，无法保证所有文章即时译完。当前针对英文到简体中文，不是全文翻译。
- 各标签顶部生成滚动 168 小时小结，展示主题匹配数量、新闻依据、学习内容和一周实践任务。不受列表搜索或日期筛选影响。规则分析不代表行业全量趋势；无新闻时不生成结论。
- AI OPC（One Person Company，一人公司）合并 AI 与 FDE 新闻，以及 Ask HN 的 AI 相关需求讨论，提供潜在客户、最小产品、获客验证与成本核算建议。它们是待验证的创业假设，不是已确认的市场需求。

验证：`python3 -m unittest -v`，`node --check static/app.js`，`node test_frontend.cjs`。

## 职业成长工作台

第五个标签页提供个人职业画像、每日最多三条相关新闻、官方学习资料、按每周时间选择的 30 分钟 / 2 小时 / 一周实践任务，以及验收清单和作品档案。支持 FDE、AI 应用、数据库 × AI、OPC 四种方向。推荐依据近七日新闻关键词、目标方向、自报技能与来源状态，属于规则建议；无相关近期新闻时不生成任务。

个人画像、任务、成果链接和复盘保存在当前浏览器的 localStorage，不发送到服务端或 GitHub。清除浏览器数据或换浏览器不会自动同步，请使用 JSON 导出保存备份（当前不提供导入）。任务标记完成前需勾选全部验收项并填写 HTTP(S) 成果链接和复盘；完成状态属于用户自评，不代表自动核验或专业认证。进入工作台后暂停每分钟刷新，避免覆盖未保存表单，手动更新仍可用。

运行 `node test_career.cjs` 验证推荐时间范围、职业排序、时间预算、任务去重、安全链接和存储。

## 数据库观察：全球 / 时序与可观测

数据库观察包含两个子标签：

- 全球数据库动态：保留原有 PostgreSQL、MongoDB、AWS Database、Azure SQL 的新闻与周报。
- 时序与可观测：以 GreptimeDB 为核心，新增官方 GitHub Releases 和 GreptimeDB、InfluxDB 官方博客，并从现有新闻中筛选相关信号。支持按项目生态（国内／国外）、产品和六个技术分组筛选；保留中英文对照、原始日期、来源错误和失败缓存。

市场地图当前列出 15 个产品／技术栈，按项目起源与主要生态组织，不是市场份额排名，也不等于产品只能在相应市场销售。数据库、指标存储和可观测平台有明确分类。Lindorm、Datadog、Elastic 等地图条目没有独立动态源时，不伪造其新闻；组合栈当前独立版本源仅为 Grafana Mimir，不代表覆盖 Loki 与 Tempo 的所有版本。

GreptimeDB 对照表可选择竞品，列出定位、查询、性能与交付成本的验证维度。暂无同资源、同负载实测结论。六组技术为：采集写入、存储成本、查询实时分析、基数与数据质量、云原生可靠性、可观测业务闭环。领域分析为摘要规则匹配与编辑框架，附原始新闻依据和可复现测试建议；产品能力、许可及价格仍需按具体版本查官方资料。

`node test_timeseries.cjs` 验证领域识别、产品映射、市场与技术过滤。版本发布包含 nightly / prerelease 等不同渠道，不能直接当作稳定版选型依据。页面提供跳转最新动态、市场地图、PK 和技术清单的入口。
